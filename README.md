# Panacea

A curated marketplace of Claude Code plugins.

## Quick Start

Add the marketplace, then install any plugin:

```
/plugin marketplace add matthewglong/so-crates
/plugin install socrates@panacea
```

## Available Plugins

### socrates

A Socratic tutor that guides learning through probing questions instead of giving direct answers. Includes an overseer hook that blocks answer-leaking.

**Usage:**

```
/tutor recursion
/tutor how does binary search work
/tutor why is my React component re-rendering
```
